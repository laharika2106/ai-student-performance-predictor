## 📸 Application Screenshots

### Student Input

The application allows students to enter their academic information.

### ML Prediction

The Random Forest model predicts the student's performance category.

### AI Recommendations

Gemini generates personalized study recommendations based on the student's academic information.

## 🏗️ Project Architecture

Student Input
     ↓
Streamlit Interface
     ↓
Random Forest ML Model
     ↓
Performance Prediction
     ↓
Gemini Generative AI
     ↓
Personalized Recommendations

## 📊 Machine Learning Model

The project uses a Random Forest Classifier.

### Input Features

- Python marks
- AI/ML marks
- DSA marks
- Attendance percentage
- Study hours

### Target

Student performance category:

- Poor
- Average
- Good
- Excellent

## 🤖 Generative AI

Gemini is used to generate personalized academic recommendations based on the student's input and predicted performance.
